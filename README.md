# FBA Pricing Lab

A standalone, responsive Amazon FBA pricing and unit economics calculator.

## What is included

- Fixed business overhead allocation
- Batch / variable operating cost allocation
- Product pricing and direct costs
- Optional VAT scenario
- Amazon referral + FBA fees
- Automatic or manual Amazon storage estimate
- ACOS-based PPC model
- Automated returns-loss allowance
- Reverse pricing
- Automatic and manual scenario comparison
- Dynamic price-composition visualization
- Local browser persistence

## Deployment

This is a static app with no build step. Import the repository into Vercel and deploy from the project root.

## Notes

Marketplace fees, VAT treatment, refund administration rules, storage rates and reimbursement treatment should be verified against the current Amazon fee tables before making decisions.
